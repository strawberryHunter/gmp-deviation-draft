## 사용법

- 순서
- 새 초안 → 8단계 입력
- 빨간 점이 있는 단계 = 빠진 항목
- 미리보기에서 초안 확인
- 내보내기: Word · Markdown · 복사
- 받은 파일의 노란 칸을 담당자가 작성 → QMS 등록
- CLI 양식(.yaml)은 더보기 → YAML 양식 가져오기 · 값은 적힌 그대로 읽음
- 초안을 CLI 양식으로: 카드 ⋯ → YAML 양식 저장 (.yaml.txt) · 덜 쓴 초안도 가능 · 그대로 다시 가져오기와 CLI 실행 가능
- 도구가 비워 두는 칸
- 6M 조사 결과
- 초안과 근거 정리까지만. 승인 문서 아님 · 서명과 승인은 검증된 QMS에서
- 등급 제안 기준
- 무균 보증에 영향 가능성 · 출하된 제품에 영향 가능성 · 데이터 완전성(ALCOA+) 우려 · 환자 안전에 영향 가능성
- 주요 공정 변수(CPP) 기준 이탈 · 규격 이탈(OOS) 결과 · 다른 배치 영향 가능성 · 조회 기간 내 동일 사업장·설비·유형 반복 (2회 이상)
- 위 기준에 해당 없음
- 기본 규칙의 예시 값 · 사내 SOP 대조 전 · 확정은 QA 검토자
- 사업장·설비·유형이 모두 같은 과거 건 · 최근 365일
- 이력 CSV가 없거나 설비·유형이 비면 '조회 안 함' (반복 없음 아님)
- 목록만 표시 · 원인 연관성은 판단 안 함
- 보고 기한
- 발견일 + 30일 (더보기 메뉴에서 변경)
- 작업 관리용 설정값 · SOP 규칙 아님 · 초안 문서에는 안 들어감
- 저장과 전송
- 입력과 파일은 이 브라우저 안에서만 처리 · 외부 전송 없음
- 기본은 탭에만 보관 · 새로고침하면 사라짐
- 더보기 → 브라우저 저장을 켜면 이 기기에 보관
- 공용 PC에서는 저장을 켜지 않음
